# TeklifHazır — Resmi Ürün ve Destek Sayfaları

Bu açık depo yalnızca TeklifHazır Chrome uzantısının herkese açık ürün, destek ve gizlilik sayfalarını içerir. Uzantının kaynak kodu, gerçek ihale verileri, özel kayıtlar veya kullanıcı bilgileri burada yayınlanmaz.

- Ürün: https://chromewebstore.google.com/detail/macdbbinnooaoicjebbkgkcphaiojpla
- Ürün sayfası: https://senih25.github.io/teklif-hazir-public/
- Gizlilik: https://senih25.github.io/teklif-hazir-public/privacy.html
- Destek: https://senih25.github.io/teklif-hazir-public/support.html

Ürün hukuki, mali ya da ihale danışmanlığı sağlamaz; EKAP'a bağlanmaz, teklif göndermez ve e-imza kullanmaz.
